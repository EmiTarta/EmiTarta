## 🚀 What I do

I own products end-to-end: talking to users, mapping their real workflow, designing the solution, building it, and shipping it to production — then measuring whether it actually saved anyone time.

I build fast by directing AI coding agents (Claude Code, Cursor, Antigravity) as part of my daily workflow: I define architecture, review and validate every change, and make the design calls, rather than writing every line by hand.
